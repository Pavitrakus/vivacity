# Vivacity site

Marketing site for the simulation runtime. Lives in `tp-cloner`.

```bash
cd tp-cloner
npm install
npm run dev
```

Open http://localhost:3000

## Product
Simulation runtime for AI agents. No signup. Book a demo only.

## Pages
- `/` landing
- `/docs` conceptual interface
- `/demo` design-partner form
- `/contact` `/privacy` `/terms`
- `/signin` `/workspace` `/newsletter` redirect away
